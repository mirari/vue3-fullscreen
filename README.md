## Installation / 安装

For Vue 3, install the current 5.x release from the main package:

```sh
npm install vue-fullscreen
```

Vue 2 projects use `npm install vue-fullscreen@legacy` (4.x, Vue 2.4+).

The new major versions include API changes. Follow the current documentation when upgrading from 3.x; the old `@next` installation and global plugin examples are historical.

新版包含 API 调整。从 3.x 升级时请参考当前文档；旧的 `@next` 安装方式和全局插件示例仅适用于历史版本。
